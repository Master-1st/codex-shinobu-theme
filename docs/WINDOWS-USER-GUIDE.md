# Windows 使用说明书

## 1. 适用范围

本主题只适用于 Windows 版 Microsoft Store Codex Desktop，并依赖 Codex++ 的可写副本与 renderer tweak 接口。Windows 11 x64 已验证；Windows 10 x64 尚未完成同等实机验收。macOS、Linux/WSL、Web、CLI、VS Code 扩展和未经 Codex++ 处理的商店原版均不支持。

## 2. 安装前准备

1. 确认 Microsoft Store Codex Desktop 能正常启动。
2. 安装并至少运行一次 Codex++。
3. 下载文件名以 `-windows.zip` 结尾的 Release 安装包。
4. 右键 ZIP →“全部解压”。不要从压缩包预览窗口直接运行脚本。
5. 不要换成另一个管理员账户安装，否则文件可能进入错误账户的 `%APPDATA%`。

## 3. 安装或更新

双击 `install.cmd`。脚本会：

1. 验证 Windows、清单 ID、构建入口和 Codex++ 目录；
2. 把新版本复制到临时目录并完成校验；
3. 把旧主题原子移动到 `%APPDATA%\codex-plusplus\theme-backups`；
4. 启用新主题；
5. 检查桌面和开始菜单中名为 `Codex++` 的快捷方式，只把失效目标修复到本机已知 Codex++ 镜像；
6. 保留单独存放的导入图片和设置。

安装后完全退出所有 Codex 窗口，再从 `Codex++` 快捷方式启动。打开 `设置 → Tweaks → 小忍主题` 确认版本和选项。

## 4. 换图与自动配色

在主题设置中点击“选择本地图片”。支持 PNG、JPG、WebP，最大 16 MB；最长边会限制到 2560 px，再保存为本地 WebP。默认开启自动配色和性能优先。

- “无缝铺满主界面”适合 16:9 横图；
- “完整显示原图”会保留完整构图，但可能出现留白；
- 人物可靠左、居中或靠右；
- 关闭自动配色只恢复默认色板，不删除图片；
- “恢复内置插画”会恢复默认背景与色板。

导入数据由 Codex++ 存在本主题的 tweak-data 目录中，不进入 Git 仓库，也不会上传。

## 5. 性能设置

“性能优先”默认开启，保留半透明外观，但取消每条消息的实时背景模糊和持续输入框呼吸动画。关闭后会恢复更完整的玻璃效果，较长对话或较弱 GPU 上可能增加合成开销。

若 Codex 本身打开或切换大型任务仍卡顿：

1. 双击 `Analyze-Codex.cmd` 做只读检查；
2. 保存未发送内容；
3. 双击 `Optimize-Codex.cmd`；
4. 按提示正常退出 Codex；若仍有残留进程，只有输入大写 `FORCE` 才会强制终止；
5. 等待重新启动。清理缓存后的第一次启动可能暂时更慢。

优化器不会修改官方程序或删除任务、附件、登录、技能、插件、设置和自定义图片。

## 6. 更新、备份与回滚

更新时重新运行新版本的 `install.cmd`。旧主题代码备份位于：

```text
%APPDATA%\codex-plusplus\theme-backups
```

要回滚：

1. 完全退出 Codex；
2. 将当前 tweak 目录改名保存；
3. 把目标备份目录复制回 `tweaks\io.github.master1st.codex-shinobu-theme`；
4. 重新启动 Codex++。

自定义图片默认独立保存，因此代码回滚不会丢图。

## 7. 卸载

双击 `Uninstall-Theme.cmd`。选择 `K` 保留导入图片，选择 `P` 同时清除。该脚本只允许处理清单声明的主题直接子目录，并会拒绝包含路径跳转字符的清单 ID。

## 8. 如何确认安装正确

- 启动入口名称是 `Codex++`；
- `设置 → Tweaks` 中能看到“小忍主题”；
- 主题目录的 `manifest.json` 版本与 Release 一致；
- 最大化和恢复窗口时，对话仍在可见工作区居中；
- 顶部应用菜单保持全长，任务标题栏位于右侧且约为窗口三分之一；
- 宠物/悬浮窗没有被主题背景染色。

遇到问题请继续阅读 [故障排查](TROUBLESHOOTING.md)。
