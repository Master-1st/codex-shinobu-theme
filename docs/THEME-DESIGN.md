# 小忍主题：配色与背景设计

这份说明记录主题如何从内置小忍图片中提取颜色，并把角色画面、聊天内容和 Windows 版 Codex 的界面层级组合起来。

![小忍主题预览](../assets/preview.png)

## 设计目标

- 小忍作为主界面的全画布背景层；聊天、回复、确认卡片和输入框以半透明玻璃层叠在画面上方。
- 背景色来自内置图片本身；换图后在本机自动提取主色并生成全套主题，避免“角色是一套颜色、界面又是另一套颜色”的割裂感。
- 保留本地图片接口，可以换成用户自有的 PNG、JPG 或 WebP；图片不会上传。
- 保持正文、代码和操作按钮的可读性，不把浅黄色直接用作小字号文字。

## 图片主色

对 `assets/shinobu-hero-safe-landscape.png` 缩小后进行 16 色中位切分取样，面积最大的颜色如下。色值是图片的近似代表色，不是版权或角色设定色。

| 角色 | 图片取样色 | 界面用途 |
| --- | --- | --- |
| 阳光柠檬黄 | `#FAE47E` | 页面底色、根画布底色、启动页 |
| 花瓣奶油粉 | `#FCECE4` | 聊天面板、弹窗、输入框和卡片 |
| 柔和薄荷绿 | `#AECFA6` | 侧栏过渡、用户消息和次级按钮 |
| 叶片薄荷绿 | `#99C8A5` | 边框、选中态和强调色的色相来源 |
| 暖驼棕 | `#C1A87D` | 阴影、分隔和角色头发的呼应色 |
| 珊瑚暖粉 | `#D3A08C` | 焦点环、提示和少量装饰 |
| 薄荷雾 | `#DAECCD` | 大面积渐变终点和悬浮层 |
| 墨褐 | `#33262C` | 正文和标题；取自角色轮廓并加深以保证对比度 |

主题中的交互色是在这些取样色上做的可读性派生：薄荷按钮使用更深的 `#70B78F`，焦点粉使用更清晰的 `#DC8298`，正文统一使用 `#33262C`。

## 背景结构

主题参考 Miku 主题的全画布做法，把角色图作为 `#root` 根画布的背景层，而不是切出独立右栏或让每个分屏分别裁图：

```text
┌────────侧栏────────┬──────────────────主画布──────────────────┐
│ 柠檬黄 → 薄荷绿   │ 小忍图片 + 柠檬黄/薄荷绿渐变（背景层）   │
│                   │ 输出、卡片和输入框（半透明玻璃前景层）   │
└───────────────────┴──────────────────────────────────────────┘
```

内置背景是 16:9 横版：人物完整放在右侧约 40%，左侧为低细节安全区。默认使用 `cover` 无缝铺满工作区，避免超宽或缩小窗口里出现图片边缘接缝；设置页仍保留 `contain`，方便优先查看完整原图。主题不再额外叠加规则白点，并通过从奶油粉到透明的柔和横向渐变降低文字区域的视觉噪声。应用菜单栏使用全长半透明表面；任务标题栏通过 Codex 的 `data-app-shell-header-edge-scroll` 实际标记单独识别，恢复原生固定定位，宽度保持约三分之一视口（最大 680 px）、高度 44 px，并在右侧保留 24 px。这样标题条不会进入正文排版，也不会叠加原生 `top-toolbar-sm` 偏移形成大块空白。主题在启动、缩放和侧栏过渡后测量可见侧栏与实际工作区：回复、长输出与输入框在侧栏右缘和工作区右缘之间居中，最大宽度 860 px，允许玻璃表面适度覆盖人物；如果可用宽度不足 360 px，则切换为紧凑模式并加强前景柔化。这样最大化、恢复窗口、覆盖式侧栏和窄窗口使用同一套坐标逻辑，同时不再把正文固定挤在左半边。完整尺寸矩阵见 [视觉与功能验收](VISUAL-QA.md)。

Codex 的宠物/进度悬浮窗使用单独的 `avatar-overlay` 渲染页面。主题会主动跳过这类辅助窗口，避免把悬浮窗的透明背景、计数文字和角色卡片一并染色。

窄窗口会提高前景渐变的不透明度，避免正文与人物线条互相干扰；角色主视觉可以在设置中单独关闭。

## 界面颜色映射

| 界面区域 | 颜色与处理 |
| --- | --- |
| 应用底层 | 小忍图片 + 柠檬黄 → 奶油黄 → 薄荷绿的多层渐变 |
| 左侧栏 | 半透明奶油黄向薄荷绿纵向过渡 |
| 主内容面板 | 奶油粉/暖白玻璃层，叠加很浅的薄荷雾 |
| 用户消息 | 薄荷绿渐变，使用更深薄荷边框 |
| 助手消息 | 半透明奶油粉卡片，保持长文本可读 |
| 标题栏 | 奶油粉 → 薄荷雾 → 暖粉的低饱和渐变 |
| 焦点与选中 | 珊瑚暖粉描边，薄荷绿底色 |
| 代码与终端 | 深墨绿背景、暖白前景，避免浅色代码区眩光 |

核心设计变量：

```css
--shinobu-yellow: #f4e96f;
--shinobu-yellow-soft: #fff5a8;
--shinobu-mint: #79bd98;
--shinobu-mint-soft: #dff1e6;
--shinobu-blush: #dc8298;
--shinobu-cream: #fffdf2;
--shinobu-ink: #33262c;
```

这里没有机械复制取样色：背景保持图片的暖黄色和薄荷绿色相，文字、边框与按钮则适度加深或提亮，以兼顾层级和对比度。

## 更换原版图片

从 **设置 → Tweaks → 小忍主题** 点击“选择本地图片”，即可导入自有图片。支持：

- PNG、JPG、WebP，单张不超过 16 MB；
- “人物安全区完整显示”或“铺满主界面”；
- 靠左、居中、靠右三种位置；
- 一键恢复内置图片；
- 关闭角色主视觉但保留整套配色。

导入图片时会同时生成可读色板；完整算法、CSS 变量和回退条件见 [换图后自动生成主题配色](AUTO-PALETTE.md)。

导入图片只会写入 Codex++ 为该主题分配的本机数据目录。主题不会发起网络请求，也不会把图片提交到仓库。

## 可访问性与动效

- 浅黄和浅粉只作为背景，正文使用墨褐色。
- 键盘焦点使用 2 px 暖粉描边，不只依赖背景色变化。
- 系统开启“减少动态效果”时，呼吸光和过渡会自动降为近乎静态。
- 右侧角色层设置为不接收鼠标事件，不影响选择文本、滚动或点击。
