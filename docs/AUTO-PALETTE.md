# 换图后自动生成主题配色

小忍主题会在用户导入 PNG、JPG 或 WebP 后，完全在 Codex 本机渲染进程中分析图片，并立即生成一套可读的界面配色。图片和分析结果都不会上传。

## 用户操作

1. 打开 `设置 → Tweaks → 小忍主题`。
2. 保持“根据图片自动配色”开启。
3. 点击“选择本地图片”并导入图片。
4. 主题会同时更新背景和色板；设置页下方显示主色、辅助色、强调色、表面色和文字色预览。
5. 关闭“根据图片自动配色”会恢复仓库内置的小忍配色，但不会删除导入的图片或已分析色板。
6. 点击“恢复内置插画”会同时恢复内置横版小忍背景和默认色板。

## 处理流程

```text
本地图片
  ↓ 解码并按最长边 2560 px 等比缩放
WebP 本地副本
  ↓ 缩小为 72 × 72 像素，仅用于取色
4096 色量化 + 颜色聚类
  ↓
主色 / 辅助色 / 强调色 / 主导背景色
  ↓ 调整饱和度和明度
表面色 / 柔和色 / 强按钮色
  ↓ WCAG 对比度校正
正文色（≥ 7:1）/ 次要正文色（≥ 4.5:1）/ 链接色（≥ 4.5:1）
  ↓
写入 CSS 变量并立即刷新主题
```

## 生成的主题变量

| 色板字段 | CSS 变量 | 用途 |
| --- | --- | --- |
| `primary` | `--shinobu-yellow` | 应用底色、侧栏主色 |
| `primarySoft` | `--shinobu-yellow-soft` | 柔和渐变、悬停背景 |
| `secondary` | `--shinobu-mint` | 边框、选中态、滚动条 |
| `secondarySoft` | `--shinobu-mint-soft` | 面板和次级按钮 |
| `accent` | `--shinobu-blush` | 焦点、强调和输入光标 |
| `surface` | `--shinobu-cream` | 对话、输入框、弹窗表面 |
| `ink` | `--shinobu-ink` | 正文文字 |
| `muted` | `--shinobu-muted` | 次要文字 |
| `strong` | `--shinobu-strong` | 主按钮和主图标 |
| `link` | `--shinobu-link` | 链接和代码强调 |

所有主要 Codex 和 VS Code 兼容色值都从这些变量派生，因此换图后不是只改变侧栏，而是同步更新对话、输入框、按钮、边框、菜单、弹窗、编辑器和焦点状态。

## 本地数据格式

导入结果写入 Codex++ 为本 tweak 提供的 `artwork.json`：

```json
{
  "name": "my-image.png",
  "dataUrl": "data:image/webp;base64,...",
  "palette": {
    "version": 1,
    "primary": "#f4e96f",
    "primarySoft": "#fff5a8",
    "secondary": "#79bd98",
    "secondarySoft": "#dff1e6",
    "accent": "#dc8298",
    "surface": "#fffdf2",
    "ink": "#33262c",
    "muted": "#715f66",
    "strong": "#3f7e5d",
    "link": "#387654"
  }
}
```

旧版本已经导入、但没有 `palette` 的图片，会在主题第一次载入时自动补算并写回，不需要重新选择文件。

## 安全与回退

- 透明度低于阈值的像素不参与聚类。
- 图片无法解码、画布不可用或色板不满足对比度时，保留图片并回退到小忍默认配色。
- 色板必须包含全部十个颜色字段，且正文与表面至少达到 7:1、次要正文与表面至少达到 4.5:1；否则不会应用。
- 主题停止、禁用自动配色或恢复内置插画时，会移除所有行内色板变量，不污染其他主题。
- 不读取图片路径以外的信息，不发起网络请求。

## 背景构图建议

为了避免人物被对话遮挡，推荐使用 16:9 横图，把人物完整放在右侧 40% 内，左侧至少保留 55% 低细节安全区。内置背景按这个规则制作，并默认使用“人物安全区完整显示”。普通照片也可以导入；如果主体居中，可在设置中切换靠左、居中、靠右或使用铺满模式。

## 验收条件

- 导入图片后背景和色板同时更新。
- 开关自动配色可在自定义色板与默认色板之间往返，图片不丢失。
- 重启 Codex 后色板保持一致。
- 旧 `artwork.json` 能自动迁移。
- 正文、次要文字和链接满足规定的最低对比度。
- 图片关闭、主题停止、辅助悬浮窗和恢复内置图片时没有残留变量。
